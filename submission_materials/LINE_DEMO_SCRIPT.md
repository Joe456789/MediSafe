# Demo 影片逐字稿：LINE 上的用藥安全管家（MediSafe）

**競賽**：2026 LINE AI 創新創業競賽｜智慧照護組
**影片長度限制**：3 分鐘內
**格式**：手機畫面錄影（LINE App 實際操作）為主，可搭配電腦畫面補充架構圖
**建議錄製方式**：手機用螢幕錄影功能（iOS「螢幕錄製」／Android內建），全程直接操作真實 Bot `@819jpvlm`，不用剪輯特效，真實感更有說服力

---

## 拍攝前準備 Checklist

- [ ] 手機 LINE 已加 `@819jpvlm` 好友
- [ ] 過敏資料登記頁先「不要」預先填過敏原（要留到片中現場示範過敏警示，效果才明顯）
- [ ] 準備一張隨便一盒藥品／藥袋的照片（真實藥盒即可，成分名稱清晰）
- [ ] 準備第二支手機（或請旁人手機）用來扮演「家屬」角色
- [ ] 確認 Cloud Run 服務是醒著的（開拍前先手動傳一次訊息熱機，避免錄影時卡在 cold start）
- [ ] 音量開到最大，錄影時同步錄旁白（或事後配音，照本逐字稿念）

**畫面**：點卡片上「查看完整報告」按鈕 → 開啟 LIFF 報告頁，展示安全 banner、食物交互作用格狀圖、完整用藥小叮嚀

**旁白**：

## 錄製小提醒

1. **時間抓緊**：上面每段旁白唸起來大約落在標註的時間範圍內，正式錄製前建議自己念一次計時，超過要精簡字句而不是加快語速（評審聽得清楚比較重要）。
2. **兩支手機的鏡頭切換**：如果不好同時入鏡，可以分開錄「使用者手機」「家屬手機」兩段素材，剪輯時左右分割畫面或前後接續呈現，重點是清楚看到「兩邊都收到通知」這件事。
3. **cold start 保險**：正式錄影前 5 分鐘先傳一次任何訊息喚醒 Cloud Run，避免錄到中間卡住等待的畫面。
4. **字幕**：建議加中文字幕（旁白內容照這份逐字稿），方便評審在無聲環境快速看懂重點，也對應「AI 服務互動展示」評分項目。
