## 拍攝前準備（這一段最重要，決定畫面拍不拍得出來）

**帳號與資料**
- [ ] 主手機 LINE 已加 `@819jpvlm` 好友；第二支手機（家屬）也加好友。
- [ ] **漏吃紀錄要提前 1～2 天準備**：漏吃只會從「提醒登記日的隔天」開始算。請前一天先在 Bot 設好「早上」和「睡前」提醒，並故意有一次不打卡，錄影時「服藥紀錄」才會出現紅色的漏吃。
- [ ] **過敏登記留到片中現場做**：錄影前不要先填過敏原。
- [ ] 過敏原要填「**系統辨識出來的英文成分名**」才會比對到。先用要拍的照片跑一次，看卡片上括號內的英文名（例如 Acetaminophen），片中選其中**一種**藥登記，就能展現「這個藥被攔下、其他藥照常分析」。

**時間與環境**
- [ ] **提醒推播要在整點才會來**：系統每小時整點檢查一次。想拍到「該吃藥囉」這則推播，請在片中要用的時段前先登記（例如 19:50 登記「晚上」→ 18:00 已過，改登記睡前 22:00，就在 22:00 整點錄），或把這段先錄好再剪進去。
- [ ] 開拍前 5 分鐘先傳一則訊息熱機，避免 Cloud Run 冷啟動卡住。
- [ ] 分析報告需要一段時間（拍照後等待畫面），剪輯時把等待**快轉**帶過，不要讓評審看空白。
- [ ] 手機開螢幕錄影並打開麥克風；也可以事後配音。

**素材**
- [ ] **一張有 2～3 種藥的照片**（處方箋、藥袋，或並排幾盒藥都可以），成分字樣要清晰。系統一次最多辨識 6 種；這張照片同時用在 ① 拍照分析和 ④ 過敏警示。
- [ ] 正式錄影前先用這張照片跑一次，確認每種藥都被辨識出來，並記下各藥的英文成分名。
- [ ] 第二支手機能同框或另外錄一段，用來展示「家屬也收到通知」。

**旁白**：

## 1:00 – 1:35｜③ 主動提醒、一鍵打卡、漏吃可查

**畫面**：
1. 點 Rich Menu「服藥提醒」→ 出現 Quick Reply 按鈕（早上／中午／晚上／睡前）→ 點「睡前提醒」→ 收到登記成功訊息。
2. 切到（預先錄好的）整點提醒畫面：收到「該吃藥囉！…」→ 點下方「我吃了」→ 收到打卡成功。
3. 點「服藥紀錄」→ 收到近 7 天紀錄（✅已吃　❌漏吃　⏳時間未到）與漏吃總次數。
4. 快速帶過 LIFF「服藥打卡」頁：每個時段一顆按鈕、近 7／14／30 天分頁、漏吃的用紅色標示。

**旁白**：
> 「點選單設定服藥提醒，早上、中午、晚上、睡前都能各自設定。時間一到，系統透過 Messaging API 主動推播，長輩只要點『我吃了』就完成打卡。想知道有沒有漏吃，點『服藥紀錄』，哪一天哪一次沒吃，紅色一眼就看到，LIFF 頁面還能切換七天、十四天、三十天。」

## 1:35 – 2:20｜④ 過敏原登記＋家屬同步通知（重點展示）

**畫面**：
1. 點 Rich Menu「過敏資料登記」→ LIFF 表單輸入過敏藥物（與要拍的藥品同名）→ 儲存。
2. 按「產生家屬通知代碼」→ 顯示 6 位數代碼。
3. 切到第二支手機：對話框輸入「綁定 XXXXXX」→ 收到綁定成功。
4. 回主手機：再傳同一張多種藥的照片 → 先收到「⚠️ 系統偵測到可能與您登記的過敏原相關」警示，接著輪播卡片中，過敏的那一種是**紅色「過敏警示」卡片**，其他藥照常出報告。
5. 切到第二支手機：同步收到家屬版警示通知。

**旁白**：
> 「每位使用者可以登記自己的過敏原。產生六位數代碼給家屬，家屬在對話框輸入『綁定』就完成連結。當長輩又拍到含過敏成分的藥，HITL Triage Gate 只攔下那一個藥、不做自動分析，其他藥照常分析，同時把警示推播給本人和所有已綁定的家屬，風險交給人來判斷。」

## 錄製小提醒

1. **先錄好、再剪**：整點提醒與等待分析的時間都不可控，建議分段錄，剪輯時拼接並快轉等待。
2. **旁白計時**：完整念一次計時，超過 3 分鐘就刪字句，聽得清楚比塞滿內容重要。
3. **字幕**：加中文字幕（內容照本逐字稿），評審在無聲環境也能看懂。
4. **不要露出**：畫面中避免拍到 `.env`、金鑰、LINE Channel Secret 等機密。
5. **說法要與實況一致**：本服務是資訊輔助，不取代醫師藥師；資料來源是美國 FDA、NIH 旗下資料庫的公開 API，不要說成「分析論文全文」。
